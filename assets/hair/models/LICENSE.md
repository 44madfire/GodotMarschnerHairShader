## Source and attribution

These assets originate from the hair dataset distributed with **CT2Hair** by Meta Research:

https://github.com/facebookresearch/CT2Hair

The GodotHair project by Ethan Truong adapted the CT2Hair strand data into the hair-card demo dataset used here:

https://github.com/2Retr0/GodotHair

GodotHair describes the conversion as CT2Hair strand data -> Alembic strand data -> Unreal Engine 5 Hair Card Generator -> Godot hair-card meshes.
